Your data, step by step
Capture
Drafts stay in this tab. Choosing “Organize with Gemini” sends only the text currently in the capture box to our server and Google Gemini.
Save
Saved memories are encrypted using WebCrypto AES-GCM in this browser’s IndexedDB. The non-extractable key is stored in the same browser profile. This protects stored records, but is not a password lock or protection against someone using your unlocked browser.
Ask
Only records you select, together with your question, are sent after you give consent. The server does not store your notes or log request text.
Export & delete
Export downloads a readable JSON copy. Deleting a memory removes its encrypted record from this browser. Clearing browser data also removes the vault and its key. There is no cross-device sync or recovery service.

  
Export your memories
This downloads a readable JSON file containing every saved memory. Anyone with the file can read it. Keep it somewhere you trust.
